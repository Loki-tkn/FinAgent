Security Self-Assessment & Architecture

Fintech security posture, permission tiers, sandbox isolation, and known risks.

Role-Based Access Control (RBAC)

Viewer Tier

Read-Only Access: Can inspect dashboards, review goal projections, view audit logs. Cannot modify budgets, stage proposals, or execute approvals.

User Tier

Personal Finance Manager: Can add/delete transactions, create savings goals, generate AI plans, execute what-if simulations, stage and approve sandbox proposals.

Admin Tier

System & Demo Administrator: Full access including database reseed, benchmark demo resets, system log inspections, and global configuration.

Credential & Data Safety Guarantee

Zero Bank Credentials Stored:

The application never requests or stores bank passwords, OTPs, or credit card numbers.

Sandbox Isolation:

All financial actions are strictly staged as pending proposals until the user explicitly authorizes them.

Deterministic & Auditable:

Rule-based mathematical models prevent non-deterministic hallucination risks.

Known Risk Register & Mitigations

Risk Identifier Description Severity Mitigation Mechanism
RISK-01 Confusion between simulated and real money Medium Persistent simulated sandbox badges, clear UI disclaimers on every view.
RISK-02 Over-aggressive budget recommendations causing hardship Medium 3-tier choice (Conservative, Balanced, Aggressive) with feasibility ratings and category caps.
RISK-03 False positive anomaly flags on seasonal expenses Low Category-normalized Z-scores and adjustable threshold parameters.
RISK-04 Unauthorized plan execution High Staged Sandbox workflow requiring explicit approval action logged to immutable audit records.
